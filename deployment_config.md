# Deployment Configuration

## Local/Cloud Use
1. Open `employee_data_validation.xlsx` in Microsoft Excel or upload it to Google Sheets.
2. Keep the `Employee Data` sheet as the primary data-entry sheet.
3. Do not remove the validation rules.
4. Add new records below the existing sample rows.
5. Save/export the completed workbook as `.xlsx`.

## Quality Check
- Test each dropdown.
- Test age boundaries.
- Test a duplicate Employee ID.
- Test zero/negative salary.
- Test an invalid date.
