# Validation Rules

| Field | Rule |
|---|---|
| Employee ID | `EMP` + 3 digits and unique |
| Department | IT, HR, Finance, Marketing, Sales |
| Gender | Male, Female, Other |
| Age | Whole number 18–60 |
| Joining Date | Valid date from 2020-01-01 to 2030-12-31 |
| Employment Type | Full-Time, Part-Time, Internship, Contract |
| Salary | Greater than 0 |

These rules are designed to restrict invalid values and maintain consistent data for later analysis.
